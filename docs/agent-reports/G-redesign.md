# Agent G — 緩急リデザイン仕様「管制室」(2026-08-20)

ユーザーフィードバック「緩急がない・注目点が分からない・Tastroのような直感的UIに」への回答。

**核となる翻訳**: Tastroの本質は宇宙モチーフではなく「情報→視覚属性の直接符号化」。
暗い無彩色の地の上で:
1. **大きさ = 重要度**
2. **色 = 切迫度**(連続ランプ、危険ほど熱い)
3. **発光・脈動 = 本物の危険だけ**(全画面で脈動は1要素まで)
4. **減光 = 停滞**(腐敗は熱くない、冷たい灰色)

## 注意モデル(視線経路)

1. **証拠リング群**(Hero、76px進捗リング) — 画面最大の視覚質量。色は使わず大きさで勝つ
2. **最悪の危険信号**(最古ブロッカー熱核 or 危険レーン) — 彩度+グロー、唯一脈動しうる
3. **次の一手**(→ プレフィックス) — アクセントシアン #4fd1ff はアクション系専用

音量予算: 彩度を持てるのは ①切迫ランプ(黄→赤) ②達成の緑 ③アクションのシアン のみ。他は全てグレースケール3階調。

## 切迫ランプ(唯一の色規則)

```
calm #aecbfa (余裕/期限なし) → warm #ffd54d (<7日/ブロッカー3日超)
→ hot #ff9838 (<3日/7日超) → critical #ff5b5b (当日・超過/14日超)
achieved #3ddc97 (達成のみの緑) / stale #5c6579 (停滞=彩度を抜く)
```

適用: ブロッカー年齢 / マイルストーン期限 / 残り日数(<14=warm, <7=hot, 超過=critical) / ヘルス(順調=calm青白, 要注意=warm, 危険=critical)。

## 実装要点

- **Hero**: タイトル24px(意味の錨)、76px SVGリング群(視覚の錨、ストローク色=期限ランプ、達成=緑フルリング+グロー+✓、中央にモノ体フラクション、クリック=カウンター更新)。右レールのヘルス/確信度は16px/700の色地チップに格上げ。残り日数は右上モノ20px。**≈%は絶対に着色・拡大しない**。
- **ワークストリーム**: divide-y廃止→独立ブロック(間隔6px)。左スパイン4px=ヘルス色+右へ9%→透明のグラデ色面。危険レーンだけ外周グロー。停滞レーンはスパイン破線+判断ゾーンのみ opacity-45 saturate-0(証拠カウンターは全輝度)。
- **ブロッカー=熱**: 36px熱核ディスク(ランプ色bg20%+同色グロー+モノ体「12日」)、行背景も同色6%。脈動は「>14日の最古」→無ければ「>7日の重大」→無ければ無し。warn-pulse 2.4s(グローのみ、scaleしない)。
- **静穏ゾーン**(自分のタスク/最近の更新): 枠を白5%、色チップ禁止、期限は6pxランプ色ドットのみ。緑の [15→18] チップは維持。
- **トップバー**: グラス(rgba(13,17,27,.62) blur22px saturate150%)。「+更新」=シアン枠+暗地。
- 背景に静的な微星野(opacity ≤4%、アニメなし)。
- コントラスト: #96a0b5/#05070e ≈ 7:1。#5c6579は12px以上限定。
